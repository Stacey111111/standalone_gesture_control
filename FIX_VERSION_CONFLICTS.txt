PROBLEM: Version conflicts with previously installed packages
问题：与之前安装的包发生版本冲突

解决方案：彻底卸载并全新安装

═══════════════════════════════════════════════════════════════════════════

METHOD 1: QUICK FIX - Uninstall and Reinstall (RECOMMENDED)
方法1：快速修复 - 卸载并重新安装（推荐）
═══════════════════════════════════════════════════════════════════════════

Step 1.1: Uninstall All Related Packages
步骤1.1：卸载所有相关包

# Uninstall mediapipe
pip3 uninstall -y mediapipe

# Uninstall opencv-python (all variants)
pip3 uninstall -y opencv-python opencv-python-headless opencv-contrib-python

# Uninstall numpy
pip3 uninstall -y numpy

# Uninstall torch (if installed)
pip3 uninstall -y torch torchvision


Step 1.2: Clear pip Cache
步骤1.2：清理pip缓存

pip3 cache purge


Step 1.3: Verify Everything is Uninstalled
步骤1.3：验证所有东西都已卸载

pip3 list --user | grep -E "mediapipe|opencv|numpy|torch"

# Should show nothing or very few results


Step 1.4: Reinstall with Compatible Versions
步骤1.4：重新安装兼容版本

# Install in order (dependencies first):

# 1. Install numpy first
pip3 install --user numpy

# 2. Install opencv-python
pip3 install --user opencv-python

# 3. Install mediapipe
pip3 install --user mediapipe

# Optional: Install torch if needed
# pip3 install --user torch


Step 1.5: Verify Installation
步骤1.5：验证安装

python3 << 'EOF'
import sys
print("Python version:", sys.version)
print("\nChecking packages...")

try:
    import numpy
    print("✅ numpy:", numpy.__version__)
except Exception as e:
    print("❌ numpy:", e)

try:
    import cv2
    print("✅ opencv-python:", cv2.__version__)
except Exception as e:
    print("❌ opencv-python:", e)

try:
    import mediapipe
    print("✅ mediapipe:", mediapipe.__version__)
except Exception as e:
    print("❌ mediapipe:", e)

print("\nTesting camera access...")
cap = cv2.VideoCapture(0)
if cap.isOpened():
    print("✅ Camera access: OK")
    cap.release()
else:
    print("❌ Camera access: FAILED")
EOF

METHOD 2: NUCLEAR OPTION - Complete User Package Cleanup
方法2：核心选项 - 完全清理用户包
═══════════════════════════════════════════════════════════════════════════

⚠️  Use this if Method 1 doesn't work
   如果方法1不起作用才使用此方法

Step 2.1: List All User-Installed Packages
步骤2.1：列出所有用户安装的包

pip3 list --user

# Review the list before proceeding


Step 2.2: Remove All User-Installed Packages
步骤2.2：删除所有用户安装的包

pip3 freeze --user | xargs pip3 uninstall -y


Step 2.3: Manually Remove User Package Directory
步骤2.3：手动删除用户包目录

# Backup first (optional):
mv ~/.local/lib/python3.10/site-packages ~/.local/lib/python3.10/site-packages.backup

# Or just remove:
rm -rf ~/.local/lib/python3.10/site-packages/*

# Note: Adjust python3.10 to your Python version if different


Step 2.4: Clear All Caches
步骤2.4：清理所有缓存

pip3 cache purge
rm -rf ~/.cache/pip


Step 2.5: Reinstall Fresh
步骤2.5：全新安装

pip3 install --user --upgrade pip
pip3 install --user numpy
pip3 install --user opencv-python
pip3 install --user mediapipe

METHOD 3: VIRTUAL ENVIRONMENT (BEST PRACTICE)
方法3：虚拟环境（最佳实践）
═══════════════════════════════════════════════════════════════════════════

Step 3.1: Create Virtual Environment
步骤3.1：创建虚拟环境

cd ~
python3 -m venv turtlebot_venv


Step 3.2: Activate Virtual Environment
步骤3.2：激活虚拟环境

source ~/turtlebot_venv/bin/activate

# Your prompt should change to show (turtlebot_venv)


Step 3.3: Install Packages in Virtual Environment
步骤3.3：在虚拟环境中安装包

# No --user flag needed inside venv
pip3 install --upgrade pip
pip3 install numpy
pip3 install opencv-python
pip3 install mediapipe


Step 3.4: Test in Virtual Environment
步骤3.4：在虚拟环境中测试

python3 -c "import mediapipe, cv2, numpy; print('✅ All OK!')"


Step 3.5: Add to Bashrc for Automatic Activation
步骤3.5：添加到Bashrc以自动激活

echo "source ~/turtlebot_venv/bin/activate" >> ~/.bashrc
source ~/.bashrc


Step 3.6: Build ROS2 Package with Virtual Environment
步骤3.6：使用虚拟环境编译ROS2包

# The virtual environment will be active when building
cd ~/turtlebot3_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select turtlebot3_gesture_ai
source install/setup.bash

SPECIFIC VERSION CONFLICTS AND SOLUTIONS
特定版本冲突及解决方案
═══════════════════════════════════════════════════════════════════════════

Conflict 1: numpy version incompatible with mediapipe
冲突1：numpy版本与mediapipe不兼容

Solution:
pip3 uninstall -y numpy
pip3 install --user "numpy<2.0"  # MediaPipe needs numpy < 2.0


Conflict 2: Multiple opencv versions installed
冲突2：安装了多个opencv版本

Solution:
pip3 uninstall -y opencv-python opencv-python-headless opencv-contrib-python
pip3 install --user opencv-python


Conflict 3: protobuf version conflict
冲突3：protobuf版本冲突

Solution:
pip3 uninstall -y protobuf
pip3 install --user "protobuf>=3.20,<4.0"


Conflict 4: Permission errors
冲突4：权限错误

Solution:
# Always use --user flag
pip3 install --user <package>

# Or use virtual environment (Method 3)

COMPLETE CLEANUP AND REINSTALL SCRIPT
完整的清理和重新安装脚本
═══════════════════════════════════════════════════════════════════════════

Save this as cleanup_and_reinstall.sh:
保存为cleanup_and_reinstall.sh：

```bash
#!/bin/bash

echo "╔══════════════════════════════════════════════════════════════╗"
echo "║  Cleanup and Reinstall Script                                ║"
echo "╚══════════════════════════════════════════════════════════════╝"

# Step 1: Uninstall everything
echo ""
echo "Step 1: Uninstalling old packages..."
pip3 uninstall -y mediapipe opencv-python opencv-python-headless opencv-contrib-python numpy torch torchvision protobuf

# Step 2: Clear cache
echo ""
echo "Step 2: Clearing cache..."
pip3 cache purge

# Step 3: Verify uninstall
echo ""
echo "Step 3: Verifying uninstall..."
pip3 list --user | grep -E "mediapipe|opencv|numpy|torch"

# Step 4: Reinstall
echo ""
echo "Step 4: Reinstalling packages..."
pip3 install --user numpy
sleep 2
pip3 install --user opencv-python
sleep 2
pip3 install --user mediapipe

# Step 5: Verify install
echo ""
echo "Step 5: Verifying installation..."
python3 << 'EOF'
try:
    import numpy
    print("✅ numpy:", numpy.__version__)
except:
    print("❌ numpy: FAILED")

try:
    import cv2
    print("✅ opencv:", cv2.__version__)
except:
    print("❌ opencv: FAILED")

try:
    import mediapipe
    print("✅ mediapipe:", mediapipe.__version__)
except:
    print("❌ mediapipe: FAILED")
EOF

echo ""
echo "╔══════════════════════════════════════════════════════════════╗"
echo "║  Cleanup Complete!                                           ║"
echo "╚══════════════════════════════════════════════════════════════╝"
```

Run it:
运行：

chmod +x cleanup_and_reinstall.sh
./cleanup_and_reinstall.sh

TROUBLESHOOTING AFTER REINSTALL
重新安装后的故障排除
═══════════════════════════════════════════════════════════════════════════

Problem 1: Still getting import errors
问题1：仍然出现导入错误

Solution:
# Check Python version
python3 --version

# Ensure using correct pip
which pip3

# Reinstall with full path
python3 -m pip install --user numpy opencv-python mediapipe


Problem 2: Packages install but can't import
问题2：包安装了但无法导入

Solution:
# Check sys.path
python3 -c "import sys; print('\n'.join(sys.path))"

# Ensure ~/.local/lib/python3.X/site-packages is in the path

# Add to bashrc if needed:
echo 'export PYTHONPATH=$HOME/.local/lib/python3.10/site-packages:$PYTHONPATH' >> ~/.bashrc
source ~/.bashrc


Problem 3: Different versions in different locations
问题3：不同位置有不同版本

Solution:
# Check all locations
python3 << 'EOF'
import numpy
print("numpy location:", numpy.__file__)
import cv2
print("opencv location:", cv2.__file__)
import mediapipe
print("mediapipe location:", mediapipe.__file__)
EOF

# If packages are in /usr/local or /usr, they're system-wide
# User packages should be in ~/.local/


Problem 4: Permission errors during uninstall
问题4：卸载时权限错误

Solution:
# For user packages, no sudo needed:
pip3 uninstall --user <package>

# If a package requires sudo to uninstall, it's system-wide
# Don't uninstall it, just install user version:
pip3 install --user --upgrade <package>
