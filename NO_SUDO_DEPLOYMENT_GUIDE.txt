PHASE 1: INSTALL PYTHON DEPENDENCIES (NO SUDO NEEDED)
阶段1：安装Python依赖（不需要SUDO）
═══════════════════════════════════════════════════════════════════════════

⚠️  ON TURTLEBOT3
   在TurtleBot3上

Step 1.1: SSH into TurtleBot3
步骤1.1：SSH到TurtleBot3

ssh ubuntu@{TURTLEBOT3_IP}


Step 1.2: Install Python Packages (User-Level, No Sudo)
步骤1.2：安装Python包（用户级别，无需Sudo）

# Install pip packages for current user only
# 仅为当前用户安装pip包

pip3 install --user mediapipe opencv-python numpy

# Verification:
pip3 list --user | grep -E "mediapipe|opencv|numpy"

# Should see:
# mediapipe       0.10.x
# opencv-python   4.x.x  
# numpy           1.x.x


Step 1.3: Update PATH (if needed)
步骤1.3：更新PATH（如果需要）

# Add user pip bin to PATH
echo 'export PATH=$HOME/.local/bin:$PATH' >> ~/.bashrc
source ~/.bashrc


Step 1.4: Verify Installation
步骤1.4：验证安装

python3 -c "import mediapipe, cv2, numpy; print('All packages OK!')"

# Should output: All packages OK!


═══════════════════════════════════════════════════════════════════════════

PHASE 2: CHECK CAMERA ACCESS (NO SUDO NEEDED)
阶段2：检查摄像头访问（不需要SUDO）
═══════════════════════════════════════════════════════════════════════════

Step 2.1: Check Camera Device
步骤2.1：检查摄像头设备

ls -la /dev/video*

# Should see:
# /dev/video0

# Check if you have access:
ls -la /dev/video0

# Typical output:
# crw-rw---- 1 root video ... /dev/video0


Step 2.2: Check Video Group Membership
步骤2.2：检查video组成员

groups

# Should see 'video' in the list
# If you see 'video', you have camera access ✅


Step 2.3: Test Camera Access
步骤2.3：测试摄像头访问

python3 << 'EOF'
import cv2
cap = cv2.VideoCapture(0)
if cap.isOpened():
    print("✅ Camera access OK!")
    cap.release()
else:
    print("❌ Camera access FAILED")
EOF

# Should output: ✅ Camera access OK!


Step 2.4: If Camera Access Fails (No Sudo Alternative)
步骤2.4：如果摄像头访问失败（无Sudo替代方案）

# Ask lab administrator to run this once:
# sudo usermod -a -G video ubuntu

# Then logout and login again
exit
ssh ubuntu@{TURTLEBOT3_IP}

# Verify:
groups | grep video


═══════════════════════════════════════════════════════════════════════════

PHASE 3: CREATE ROS2 WORKSPACE (NO SUDO NEEDED)
阶段3：创建ROS2工作空间（不需要SUDO）
═══════════════════════════════════════════════════════════════════════════

Step 3.1: Create Workspace Directory
步骤3.1：创建工作空间目录

mkdir -p ~/turtlebot3_ws/src
cd ~/turtlebot3_ws/src


Step 3.2: Create Package Using ROS2 Tools
步骤3.2：使用ROS2工具创建包

ros2 pkg create --build-type ament_python turtlebot3_gesture_ai

# This does NOT require sudo


Step 3.3: Create Directory Structure
步骤3.3：创建目录结构

cd turtlebot3_gesture_ai

mkdir -p turtlebot3_gesture_ai
mkdir -p resource
mkdir -p launch

# Create marker files
touch turtlebot3_gesture_ai/__init__.py
touch resource/turtlebot3_gesture_ai


Step 3.4: Verify Structure
步骤3.4：验证结构

ls -la

# Should see:
# turtlebot3_gesture_ai/
# resource/
# launch/
# package.xml
# setup.py
# setup.cfg

PHASE 4: TRANSFER FILES TO TURTLEBOT3 (NO SUDO NEEDED)
阶段4：传输文件到TurtleBot3（不需要SUDO）
═══════════════════════════════════════════════════════════════════════════

Method 1: Using SCP (From Your Computer)
方法1：使用SCP（从您的电脑）

# On your computer (not TurtleBot3):
# 在您的电脑上（不是TurtleBot3）：

# Copy main Python file
scp standalone_turtlebot_gesture_control.py \
  ubuntu@{TURTLEBOT3_IP}:~/turtlebot3_ws/src/turtlebot3_gesture_ai/turtlebot3_gesture_ai/standalone_gesture_node.py

# Copy package.xml
scp turtlebot3_gesture_ai_package.xml \
  ubuntu@{TURTLEBOT3_IP}:~/turtlebot3_ws/src/turtlebot3_gesture_ai/package.xml

# Copy setup.py
scp turtlebot3_gesture_ai_setup.py \
  ubuntu@{TURTLEBOT3_IP}:~/turtlebot3_ws/src/turtlebot3_gesture_ai/setup.py

# Copy setup.cfg
scp turtlebot3_gesture_ai_setup.cfg \
  ubuntu@{TURTLEBOT3_IP}:~/turtlebot3_ws/src/turtlebot3_gesture_ai/setup.cfg


Method 2: Direct Copy and Paste (On TurtleBot3)
方法2：直接复制粘贴（在TurtleBot3上）

# SSH into TurtleBot3
ssh ubuntu@{TURTLEBOT3_IP}

# Create main node file
cd ~/turtlebot3_ws/src/turtlebot3_gesture_ai/turtlebot3_gesture_ai/
vim standalone_gesture_node.py

# Copy and paste the content from standalone_turtlebot_gesture_control.py
# Save: ESC, :wq

# Create/update package.xml
cd ~/turtlebot3_ws/src/turtlebot3_gesture_ai/
vim package.xml

# Copy and paste the content from turtlebot3_gesture_ai_package.xml
# Save: ESC, :wq

# Create/update setup.py
vim setup.py

# Copy and paste the content from turtlebot3_gesture_ai_setup.py
# Save: ESC, :wq

# Create/update setup.cfg
vim setup.cfg

# Copy and paste the content from turtlebot3_gesture_ai_setup.cfg
# Save: ESC, :wq


Method 3: Using USB Drive
方法3：使用U盘

# 1. On your computer: Copy files to USB drive
# 2. Plug USB into TurtleBot3
# 3. Mount USB (usually auto-mounted at /media/ubuntu/...)
# 4. Copy files:

cp /media/ubuntu/*/standalone_turtlebot_gesture_control.py \
   ~/turtlebot3_ws/src/turtlebot3_gesture_ai/turtlebot3_gesture_ai/standalone_gesture_node.py

cp /media/ubuntu/*/turtlebot3_gesture_ai_package.xml \
   ~/turtlebot3_ws/src/turtlebot3_gesture_ai/package.xml

cp /media/ubuntu/*/turtlebot3_gesture_ai_setup.py \
   ~/turtlebot3_ws/src/turtlebot3_gesture_ai/setup.py

cp /media/ubuntu/*/turtlebot3_gesture_ai_setup.cfg \
   ~/turtlebot3_ws/src/turtlebot3_gesture_ai/setup.cfg

PHASE 5: BUILD ROS2 PACKAGE (NO SUDO NEEDED)
阶段5：编译ROS2包（不需要SUDO）
═══════════════════════════════════════════════════════════════════════════

Step 5.1: Navigate to Workspace
步骤5.1：进入工作空间

cd ~/turtlebot3_ws


Step 5.2: Source ROS2 Humble
步骤5.2：Source ROS2 Humble

source /opt/ros/humble/setup.bash


Step 5.3: Build Package (No Sudo Required)
步骤5.3：编译包（不需要Sudo）

colcon build --packages-select turtlebot3_gesture_ai

# This does NOT require sudo
# Wait for build to complete...

# Expected output:
# Starting >>> turtlebot3_gesture_ai
# Finished <<< turtlebot3_gesture_ai [X.XXs]
#
# Summary: 1 package finished [X.XXs]


Step 5.4: Source Workspace
步骤5.4：Source工作空间

source install/setup.bash

# Add to bashrc for automatic sourcing
echo "source ~/turtlebot3_ws/install/setup.bash" >> ~/.bashrc


Step 5.5: Verify Installation
步骤5.5：验证安装

ros2 pkg list | grep turtlebot3_gesture_ai

# Should output: turtlebot3_gesture_ai ✅

ros2 pkg executables turtlebot3_gesture_ai

# Should output:
# turtlebot3_gesture_ai gesture_control ✅


═══════════════════════════════════════════════════════════════════════════

PHASE 6: RUN THE SYSTEM (NO SUDO NEEDED)
阶段6：运行系统（不需要SUDO）
═══════════════════════════════════════════════════════════════════════════

Step 6.1: Launch TurtleBot3 Robot
步骤6.1：启动TurtleBot3机器人

# Terminal 1 on TurtleBot3:
export TURTLEBOT3_MODEL=waffle_pi
export ROS_DOMAIN_ID=30
ros2 launch turtlebot3_bringup robot.launch.py

# No sudo needed!


Step 6.2: Run Gesture Control Node
步骤6.2：运行手势控制节点

# Terminal 2 on TurtleBot3:
export ROS_DOMAIN_ID=30
source ~/turtlebot3_ws/install/setup.bash
ros2 run turtlebot3_gesture_ai gesture_control

# No sudo needed!


Step 6.3: Test Gestures
步骤6.3：测试手势

# Make gestures in front of TurtleBot3's camera:
# 在TurtleBot3摄像头前做手势：

👆 Point up     → Forward
👇 Point down   → Backward
👈 Thumb left   → Turn left
👉 Thumb right  → Turn right
✋ Open palm    → Stop

什么需要SUDO（以及替代方案）

What Does NOT Require Sudo:
不需要Sudo的操作：

What Might Require Sudo (If You Don't Have Access):

TROUBLESHOOTING WITHOUT SUDO
无需SUDO的故障排除
═══════════════════════════════════════════════════════════════════════════

Problem 1: pip3 command not found
问题1：找不到pip3命令

Solution (No Sudo):
python3 -m pip install --user mediapipe opencv-python numpy


Problem 2: Camera access denied
问题2：摄像头访问被拒绝

Solution (Ask Admin Once):
# Ask lab administrator to run:
# sudo usermod -a -G video ubuntu

# Then logout and login:
exit
ssh ubuntu@{TURTLEBOT3_IP}


Problem 3: Package import error
问题3：包导入错误

Solution (No Sudo):
# Reinstall with --user flag
pip3 install --user --upgrade mediapipe opencv-python numpy

# Ensure PATH includes user bin:
echo 'export PATH=$HOME/.local/bin:$PATH' >> ~/.bashrc
source ~/.bashrc


Problem 4: colcon build fails
问题4：colcon编译失败

Solution (No Sudo):
# Check if all files are in place:
ls -la ~/turtlebot3_ws/src/turtlebot3_gesture_ai/

# Rebuild with verbose output:
cd ~/turtlebot3_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select turtlebot3_gesture_ai --event-handlers console_direct+


Problem 5: ROS2 commands not found
问题5：找不到ROS2命令

Solution (No Sudo):
# Source ROS2:
source /opt/ros/humble/setup.bash

# Add to bashrc:
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
