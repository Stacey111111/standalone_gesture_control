PHASE 1: INSTALL DEPENDENCIES ON TURTLEBOT3 (10 minutes)
阶段1：在TurtleBot3上安装依赖（10分钟）
═══════════════════════════════════════════════════════════════════════════

⚠️  ALL COMMANDS RUN ON TURTLEBOT3
   所有命令在TurtleBot3上执行

Step 1.1: SSH into TurtleBot3
步骤1.1：SSH登录TurtleBot3

# From your computer:
ssh ubuntu@{TURTLEBOT3_IP}

# Enter password


Step 1.2: Install Python Dependencies
步骤1.2：安装Python依赖

sudo apt update

# Install pip if not installed
sudo apt install -y python3-pip

# Install MediaPipe and OpenCV
pip3 install --user mediapipe opencv-python numpy

# Verify installation
pip3 list | grep -E "mediapipe|opencv|numpy"


Step 1.3: Verify Camera
步骤1.3：验证摄像头

ls /dev/video*

# Should see: /dev/video0 (TurtleBot3's camera)

# Test camera access
python3 -c "import cv2; cap = cv2.VideoCapture(0); print('Camera OK' if cap.isOpened() else 'Camera FAIL'); cap.release()"


═══════════════════════════════════════════════════════════════════════════

PHASE 2: CREATE ROS2 PACKAGE (5 minutes)
阶段2：创建ROS2包（5分钟）
═══════════════════════════════════════════════════════════════════════════

⚠️  ON TURTLEBOT3
   在TurtleBot3上

Step 2.1: Create Workspace (if not exists)
步骤2.1：创建工作空间（如果不存在）

mkdir -p ~/turtlebot3_ws/src
cd ~/turtlebot3_ws/src


Step 2.2: Create Package
步骤2.2：创建包

ros2 pkg create --build-type ament_python turtlebot3_gesture_ai


Step 2.3: Create Directory Structure
步骤2.3：创建目录结构

cd turtlebot3_gesture_ai
mkdir -p turtlebot3_gesture_ai
mkdir -p resource
mkdir -p launch

# Create marker files
touch turtlebot3_gesture_ai/__init__.py
touch resource/turtlebot3_gesture_ai


═══════════════════════════════════════════════════════════════════════════

PHASE 3: ADD FILES (5 minutes)
阶段3：添加文件（5分钟）
═══════════════════════════════════════════════════════════════════════════

Step 3.1: Copy Main Python File
步骤3.1：复制主Python文件

# Copy the standalone_turtlebot_gesture_control.py to:
cd ~/turtlebot3_ws/src/turtlebot3_gesture_ai/turtlebot3_gesture_ai/

# Create the file
vim standalone_gesture_node.py

# Paste the content from standalone_turtlebot_gesture_control.py
# (or use scp to copy from your computer)


Step 3.2: Create package.xml
步骤3.2：创建package.xml

cd ~/turtlebot3_ws/src/turtlebot3_gesture_ai/

cat > package.xml << 'EOF'
<?xml version="1.0"?>
<?xml-model href="http://download.ros.org/schema/package_format3.xsd" schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>turtlebot3_gesture_ai</name>
  <version>1.0.0</version>
  <description>Standalone AI gesture control for TurtleBot3</description>
  <maintainer email="your@email.com">Your Name</maintainer>
  <license>Apache-2.0</license>

  <depend>rclpy</depend>
  <depend>geometry_msgs</depend>
  <depend>sensor_msgs</depend>

  <test_depend>ament_copyright</test_depend>
  <test_depend>ament_flake8</test_depend>
  <test_depend>ament_pep257</test_depend>
  <test_depend>python3-pytest</test_depend>

  <export>
    <build_type>ament_python</build_type>
  </export>
</package>
EOF


Step 3.3: Create setup.py
步骤3.3：创建setup.py

cat > setup.py << 'EOF'
from setuptools import setup
import os
from glob import glob

package_name = 'turtlebot3_gesture_ai'

setup(
    name=package_name,
    version='1.0.0',
    packages=[package_name],
    data_files=[
        ('share/ament_index/resource_index/packages',
            ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
    ],
    install_requires=['setuptools'],
    zip_safe=True,
    maintainer='Your Name',
    maintainer_email='your@email.com',
    description='Standalone AI gesture control for TurtleBot3',
    license='Apache-2.0',
    tests_require=['pytest'],
    entry_points={
        'console_scripts': [
            'gesture_control = turtlebot3_gesture_ai.standalone_gesture_node:main',
        ],
    },
)
EOF


Step 3.4: Create setup.cfg
步骤3.4：创建setup.cfg

cat > setup.cfg << 'EOF'
[develop]
script_dir=$base/lib/turtlebot3_gesture_ai
[install]
install_scripts=$base/lib/turtlebot3_gesture_ai
EOF

PHASE 5: RUN THE SYSTEM (5 minutes)
阶段5：运行系统（5分钟）
═══════════════════════════════════════════════════════════════════════════

Step 5.1: Launch TurtleBot3 Robot
步骤5.1：启动TurtleBot3机器人

步骤5.2：运行手势控制

source ~/turtlebot3_ws/install/setup.bash
ros2 run turtlebot3_gesture_ai gesture_control


Step 5.3: View Camera Window (Optional)
步骤5.3：查看摄像头窗口（可选）

步骤5.4：测试手势

👈 Thumb left   → Robot turns left
👉 Thumb right  → Robot turns right

TROUBLESHOOTING
故障排除
═══════════════════════════════════════════════════════════════════════════

Problem 1: Camera not found
问题1：找不到摄像头

Solution:
ls /dev/video*
# Verify /dev/video0 exists

# Check camera permissions:
sudo usermod -a -G video ubuntu
# Reboot TurtleBot3


Problem 2: MediaPipe import error
问题2：MediaPipe导入错误

Solution:
pip3 install --user --upgrade mediapipe opencv-python

# Verify:
python3 -c "import mediapipe; import cv2; print('OK')"


Problem 3: OpenCV window not showing
问题3：OpenCV窗口不显示

Solution:
# Use SSH with X11 forwarding:
ssh -X ubuntu@{TURTLEBOT3_IP}

# Or run headless (no window):
# Comment out cv2.imshow() and cv2.waitKey() in code


Problem 4: Robot not moving
问题4：机器人不移动

Solution:
# Check if robot.launch.py is running:
ros2 node list | grep turtlebot3

# Check velocity topic:
ros2 topic echo /cmd_vel

# Verify gesture recognition is working:
# (text on screen should change)


Problem 5: Package not found after build
问题5：编译后找不到包

Solution:
cd ~/turtlebot3_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select turtlebot3_gesture_ai
source install/setup.bash

PERFORMANCE OPTIMIZATION
性能优化
═══════════════════════════════════════════════════════════════════════════

If TurtleBot3 processing is slow:
如果TurtleBot3处理较慢：

1. Reduce Camera Resolution
   降低摄像头分辨率

   # In the code, change:
   self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, 320)   # was 640
   self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 240)  # was 480


2. Reduce Frame Rate
   降低帧率

   # In the code, change timer:
   self.timer = self.create_timer(0.2, self.process_frame)  # 5 Hz instead of 10 Hz


3. Disable Display Window
   禁用显示窗口

   # Comment out in code:
   # cv2.imshow('TurtleBot3 Gesture Control', frame)
   # cv2.waitKey(1)
